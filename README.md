# ⚡ nova-toolkit

A small Python command-line toolkit by **Tanvir Khan Nova**.

| Command | What it does |
|---|---|
| `password` | Rates how strong a password is and suggests improvements |
| `hash` | Prints the SHA-256 / SHA-1 / MD5 hash of a file to verify downloads |

## Usage

```bash
python nova.py password "MyP@ssw0rd2026"
python nova.py hash ./some-file.zip
```

Requires Python 3.8+ — no extra packages.
